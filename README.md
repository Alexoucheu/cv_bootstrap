# cv_bootstrap - English

A project for the class 'Tools for developing websites' ("Outils_de_developpement_site_web") *of johannchopin* at DFHI-ISFATES.

---

> The user interface has been tested on :
> - Iphone 14/15/16 IOS w/ 18.6
> - Galaxy Tab 9
> - Laptop with MDPI screen

---

# How to access the website (two solutions) :
 - Access through my website: [here](https://graoully-ag.worldlite.fr/web-cv-gaildratalexis/)
 - Download it manually

## Download it manually

Make sure you have npm installed, if not
```bash
sudo apt install npm
```

After change your repersitory to go in the one where you want to download the server and clone the git
```bash
cd yourrepersitory/
git clone "https://github.com/Alexoucheu/cv_bootstrap"
```

Go to the repersitory cv_bootstrap that has been created 
```bash
cd cv_boostsrap/
```

Install the necessary dependencies
```bash
npm install
```

You must also have nodejs installed if not install it.

Go to the website repersitory
```bash
cd website/
```

Start the server
```bash
npm run preview
```

And after open your navigator, go to a new page and for the url put 'localhost:xxxx/', with xxxx the port given by npm.

That's all have fun !

## Le télécharger manuellement

Vérifier si vous avez npm d'installé, si non
```bash
sudo apt install npm
```

Ensuite changez de répertoire pour aller dans celui où vous voulez installer le serveur et clonez le git
```bash
cd votrerepertoire/
git clone "https://github.com/Alexoucheu/cv_bootstrap"
```

Allez au répertoire cv_bootstrap ainsi crée
```bash
cd cv_boostsrap/
```

Installez les modules nécéssaires
```bash
npm install
```

Il faut aussi avoir nodejs d'installé sinon installez-le.

Allez au répertoire site
```bash
cd site/
```

Démarrez le serveur
```bash
npm run preview
```

Et ensuite dans votre navigateur web ouvrez une nouvelle page et tapez 'localhost:xxxx/', avec xxxx le port donné par npm.

Et voila c'est tout bon !
