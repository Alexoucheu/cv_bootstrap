# Bootstrap w/ Vite

Include [Bootstrap](https://getbootstrap.com)'s source Sass and individual JavaScript plugins with [Vite](https://vitejs.dev/).

## How to use

```bash
# Install dependencies
npm install

# Start the dev server
npm start
```
